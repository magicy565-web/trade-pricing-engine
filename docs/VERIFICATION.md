直接浏览器访问本地服务被当前环境的管理员策略拦截，返回 `ERR_BLOCKED_BY_ADMINISTRATOR`。没有修改或绕过该策略。改为读取自有页面源码并进行**不访问网络**的组件渲染；因此只报告 UI 组件渲染结果，不报告浏览器完整 E2E 成功。
